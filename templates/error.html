Set the model up

The dataset is not stored in the project, so the model has to be trained on your machine once. Run these commands from the project folder in PowerShell.

  1. Install the dependencies (first time only):

    python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt

  2. Download the dataset. This needs a free Kaggle account — put your kaggle.json in %USERPROFILE%\.kaggle\ first. Check the dataset page and its licence before you use it. 

    kaggle datasets download -d shivamb/real-or-fake-fake-jobposting-prediction -p data/raw --unzip

  3. Train the model, then create the evaluation report:

    python -m ml.train_model
python -m ml.evaluate_model

Full details, including the manual download route: data/README.md and README.md.
